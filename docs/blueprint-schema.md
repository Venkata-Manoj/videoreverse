# Universal Blueprint Schema

The Universal Blueprint is the core data structure that captures everything needed to recreate a video. It's generated by the synthesis step and used by the compiler to produce model-specific prompts.

## Structure

```json
{
  "global_aesthetic": {
    "art_style": "string",
    "color_grading": "string",
    "lighting_setup": "string",
    "audio_mood": "string | null"
  },
  "chronological_shots": [
    {
      "shot_index": 0,
      "start_time_seconds": 0.0,
      "end_time_seconds": 5.0,
      "duration_seconds": 5.0,
      "camera_direction": "string | null",
      "framing_type": "string | null",
      "action_and_motion": "string | null",
      "environment_context": "string | null",
      "negative_elements": ["string"],
      "frame_references": [
        {
          "frame_index": 0,
          "timestamp_seconds": 0.0,
          "motion_level": "low | medium | high",
          "relevance": "key_frame | transition_frame | supporting"
        }
      ],
      "shot_boundaries": {
        "detected_by": "motion_change | scene_cut | audio_cue | manual",
        "confidence": "high | medium | low",
        "correlated_frames": [0, 1]
      }
    }
  ]
}
```

## Fields

### Global Aesthetic

| Field | Type | Description |
|-------|------|-------------|
| `art_style` | string | Overall visual style (e.g., "photorealistic CGI", "live-action documentary", "2D anime") |
| `color_grading` | string | Color palette and grading (e.g., "warm golden hour", "cool blue tones", "high-contrast neon") |
| `lighting_setup` | string | Lighting configuration (e.g., "soft diffused studio lights", "harsh direct sunlight") |
| `audio_mood` | string \| null | Audio mood classification (e.g., "dynamic", "contemplative", "atmospheric") |

### Chronological Shot

| Field | Type | Description |
|-------|------|-------------|
| `shot_index` | int | Zero-based sequential index |
| `start_time_seconds` | float | When this shot begins (seconds) |
| `end_time_seconds` | float | When this shot ends (seconds) |
| `duration_seconds` | float | Shot duration (must be > 0) |
| `camera_direction` | string \| null | Camera movement (e.g., "static tripod", "slow push-in", "handheld shake") |
| `framing_type` | string \| null | Shot framing (e.g., "wide", "close-up", "over-the-shoulder") |
| `action_and_motion` | string \| null | What happens in this shot |
| `environment_context` | string \| null | Setting, background, spatial context |
| `negative_elements` | string[] | Elements that should NOT appear |
| `frame_references` | FrameReference[] | Which frames informed this analysis |
| `shot_boundaries` | ShotBoundary \| null | How the boundary was detected |

### Frame Reference

| Field | Type | Description |
|-------|------|-------------|
| `frame_index` | int | Zero-based index in timeline_frames |
| `timestamp_seconds` | float | Frame timestamp |
| `motion_level` | "low" \| "medium" \| "high" | Motion at this frame |
| `relevance` | "key_frame" \| "transition_frame" \| "supporting" | Frame importance |

### Shot Boundary

| Field | Type | Description |
|-------|------|-------------|
| `detected_by` | "motion_change" \| "scene_cut" \| "audio_cue" \| "manual" | Detection method |
| `confidence` | "high" \| "medium" \| "low" | Confidence level |
| `correlated_frames` | int[] | Frame indices at the boundary |

## Validation Rules

- `chronological_shots` must have at least 1 shot
- `duration_seconds` must be > 0
- `start_time_seconds` must be < `end_time_seconds`
- `shot_index` must be >= 0

## Usage

### Programmatic Access

```python
from src.schemas.blueprint import UniversalBlueprint

# Load from dict
blueprint = UniversalBlueprint(**data)

# Access fields
print(blueprint.global_aesthetic.art_style)
print(blueprint.get_total_duration())
print(blueprint.get_shot_count())
```

### Validation

```python
from utils.validation import validate_blueprint, sanitize_blueprint

# Strict validation (raises BlueprintValidationError)
validate_blueprint(data)

# Sanitized validation (auto-fixes common issues)
clean = sanitize_blueprint(data)
```

### JSON Schema

The JSON Schema is auto-generated from the Pydantic models:

```python
from src.schemas.blueprint import UniversalBlueprint
schema = UniversalBlueprint.model_json_schema()
```
